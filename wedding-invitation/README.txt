موقع دعوة زفاف لينة ميار وإلياس
=================================

الملف الرئيسي: index.html

التشغيل محلياً:
1. افتح index.html بالنقر المزدوج، وسيعمل في المتصفح.
2. لتعديل رقم واتساب، افتح الملف بمحرر نصوص وابحث عن:
   const WHATSAPP_NUMBER = "213XXXXXXXXX";
   استبدل X برقم صاحب الدعوة الجزائري كاملاً بعد 213، دون + أو مسافات.
3. يمكن تعديل أسماء العروسين والمكان والنصوص داخل الملف.

النشر المجاني عبر GitHub Pages:
1. أنشئ حساباً في https://github.com
2. أنشئ مستودعاً جديداً باسم wedding-invitation واجعله Public.
3. ارفع index.html إلى جذر المستودع (Add file > Upload files).
4. افتح Settings > Pages.
5. في Build and deployment اختر Deploy from a branch.
6. اختر Branch: main و Folder: /(root)، ثم Save.
7. انتظر قليلاً وافتح الرابط الذي يظهر في صفحة Pages:
   https://اسم-المستخدم.github.io/wedding-invitation/

ملاحظات:
- لا توجد قاعدة بيانات أو خدمات مدفوعة.
- عداد التنازلي مضبوط على 19 ديسمبر 2026 الساعة 18:00 بالتوقيت المحلي للجهاز.
- رابط الخريطة يبحث عن "المنار - تبسة". تحقق من المكان الدقيق قبل إرسال الدعوات.
- الخطوط من Google Fonts؛ إذا لم يتوفر الإنترنت سيستخدم المتصفح خطوطاً بديلة.
- زر واتساب يحتاج رقم الهاتف ليعمل.
